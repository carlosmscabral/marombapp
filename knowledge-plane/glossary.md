# Glossary

| Term | Definition |
|---|---|
| ALLOWED_UID | The single authorized Firebase Auth user UID permitted to read/write Firestore documents and invoke protected `/api/*` BFF endpoints. |
| RestBar | The sticky top bar in `InGym` that tracks elapsed count-up rest time after set completion and survives navigation/reload via `sessionStorage`. |
| Progressive Overload History | The inline display of the last 3 completed session executions (weights and reps) per exercise during an active workout. |
